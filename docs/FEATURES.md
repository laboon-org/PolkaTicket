# Features

## Core Features

### 🎫 NFT Ticketing
- Mint tickets as NFTs (PSP34 standard)
- Transfer ownership
- QR code generation
- Ticket verification

### 🌉 Cross-Chain (XCM)
- Transfer tickets between Astar ↔ Moonbeam
- Multi-parachain support
- Cross-chain state tracking

### 🔐 Privacy
- Zero-knowledge proof generation
- Anonymous verification
- Privacy-preserving check-ins

### 🎨 Dynamic NFTs
- Metadata evolution based on usage
- Achievement badges
- Tier upgrades (Standard → VIP)
- Attendance tracking

### 🗳️ Governance
- DAO proposals
- Community voting
- Treasury management
- On-chain execution

### 🏪 Marketplace
- Buy/sell tickets
- Organizer royalties
- Price discovery
- Secondary market

## Technical Features

- Multi-wallet support (Polkadot.js, Talisman, SubWallet)
- IPFS integration for metadata
- Mock data system for offline testing
- Responsive design
- Real-time updates
