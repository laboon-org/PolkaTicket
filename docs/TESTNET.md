# Testnet Guide

## Network Information

- **Network:** Shibuya Testnet (Astar)
- **Token:** SBY
- **Chain ID:** 81

## Get Testnet Tokens

### Method 1: Astar Portal
```
https://portal.astar.network/shibuya-testnet/assets
```
1. Connect wallet
2. Click "Faucet"
3. Receive ~1 SBY

### Method 2: Discord
```
https://discord.gg/astarnetwork
```
Channel: `#shibuya-faucet`
Command: `/drip YOUR_ADDRESS`

### Method 3: Matrix
```
https://matrix.to/#/#shibuya-faucet:matrix.org
```
Command: `!drip YOUR_ADDRESS`

## Wallet Setup

1. Install Polkadot.js Extension
2. Create account
3. Switch to Shibuya network
4. Request tokens from faucet

## Testing

Recommended balance: 2-3 SBY for full testing

Gas costs:
- NFT mint: ~0.01-0.05 SBY
- Transfer: ~0.001 SBY
- Contract call: ~0.005-0.02 SBY
